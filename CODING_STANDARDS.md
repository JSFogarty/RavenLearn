# Raven Learn Coding Standards

## Product Rules

- Build in PRD phase order.
- Keep AI explanations grounded in structured chart facts generated by the app.
- Never hardcode API keys or secrets.
- Avoid direct financial advice language such as "buy", "sell", or "guaranteed".
- Use cautious educational labels for chart annotations.

## Engineering Rules

- Prefer TypeScript and strict types for product logic.
- Keep route surfaces desktop-first and responsive.
- Use existing UI primitives before adding new abstractions.
- Keep data providers behind clear library interfaces.
- Add focused tests when shared behavior, data normalization, or analysis rules are introduced.
